# Biblioteca de estructuras narrativas

## Principio

La estructura se elige según el tipo de historia. No todos los videos necesitan giro, tres escenas, cuenta atrás o cierre concluyente.

## Modelos narrativos disponibles

### E01 — Misterio con evidencia

Pregunta concreta → contexto mínimo → indicios ordenados → contradicciones o límites → qué se sabe y qué permanece abierto.

Útil para: casos sin resolver, grabaciones, objetos o sucesos extraños. No fingir una resolución.

### E02 — Historia con giro

Consecuencia o pregunta → contexto → progresión de hechos → revelación que reinterpreta lo anterior → consecuencia final.

Útil cuando existe un giro real y verificable. No fabricar una sorpresa artificial.

### E03 — Relato cronológico

Situación inicial → detonante → decisiones y consecuencias → momento decisivo → desenlace.

Útil para acontecimientos históricos y biografías. Se puede romper la cronología si mejora la comprensión y no confunde.

### E04 — Mito frente a evidencia

Creencia popular → origen de la versión → evidencia disponible → qué contradice o matiza la creencia → conclusión proporcionada.

Útil para mitos, leyendas y datos distorsionados. No ridiculizar versiones culturales ni presentar una explicación parcial como verdad absoluta.

### E05 — Investigación por pistas

Hallazgo inicial → pista 1 → pista 2 → pista decisiva o contradicción → interpretación razonada.

Útil cuando el espectador puede descubrir la respuesta junto con el narrador.

### E06 — Explicación progresiva

Pregunta útil → explicación sencilla → ejemplo → implicación o excepción → síntesis.

Útil para conceptos, ciencia, historia y temas educativos.

### E07 — Lista con progresión

Promesa de la lista → elementos ordenados por importancia, rareza o intensidad → elemento final que completa la idea → cierre.

Útil cuando los elementos comparten un criterio real. El último elemento no tiene que ser «el más impactante» si no lo es.

### E08 — Dos versiones en tensión

Versión A → versión B → evidencias de cada una → puntos de acuerdo y desacuerdo → qué puede concluirse.

Útil para casos controvertidos. Evita falsa equivalencia cuando la evidencia favorece claramente una versión.

## Reglas flexibles

- El gancho suele preceder al contexto, pero puede abrirse con una escena si se entiende.
- El contexto debe ser el mínimo que permita comprender lo que sigue.
- Un giro es opcional; una revelación solo se utiliza si existe.
- La escalada puede ser emocional, informativa, causal o visual; no necesita exactamente tres escenas.
- Cada bloque debe añadir información, tensión, consecuencia o perspectiva. Si no cambia nada, probablemente sobra.
- El cierre debe resolver la promesa principal o reconocer con claridad por qué no puede resolverse.
- La duración la determina el tema y el objetivo, no una regla fija de 60–90 segundos.

## Cómo elegir

Antes de redactar, el escritor propone hasta tres estructuras posibles y selecciona la que mejor:

1. Sigue la lógica real de los acontecimientos.
2. Permite entender la pregunta central.
3. Entrega la información en el orden más atractivo sin distorsionarla.
4. Reserva una recompensa significativa para el desarrollo.

Si ninguna estructura de la biblioteca encaja, puede diseñar una nueva y registrarla como provisional.
