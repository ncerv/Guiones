# Historial de versiones

## 2.1 — 17 de noviembre de 2026

- Se incorpora un prompt maestro que orquesta los módulos y define los modos de uso.
- Se formaliza la arquitectura en tres capas: motor narrativo, adaptador de plataforma y sistema de aprendizaje.
- Se incorpora el perfil inicial de Facebook Reels basado en documentación pública de Meta consultada en noviembre de 2026.
- Se añade una evaluación editorial previa a la entrega.
- Se amplía el brief para incluir nicho, identidad del canal y valor para el espectador.
- Se conecta el registro de resultados con métricas disponibles y se refuerza que no deben inferirse causas a partir de una sola métrica.
- Se preservan las bibliotecas anteriores como recursos, no como leyes universales.
