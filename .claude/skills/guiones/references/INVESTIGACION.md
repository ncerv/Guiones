# Investigación y verificación

## Objetivo

Construir una base factual suficiente antes de escribir. La investigación debe ayudar a encontrar una historia interesante, no solo acumular datos.

## Clasificación obligatoria

Etiqueta cada afirmación importante como una de estas categorías:

- **Hecho verificado:** respaldado por fuentes confiables.
- **Testimonio:** algo que una persona afirma haber vivido o presenciado.
- **Tradición o leyenda:** relato transmitido culturalmente, no demostrado como hecho.
- **Versión discutida:** hay explicaciones o fuentes que discrepan.
- **Hipótesis:** interpretación posible, no confirmada.
- **Desconocido:** no hay evidencia suficiente para responder.

No conviertas un testimonio en hecho probado ni una leyenda en suceso histórico.

## Procedimiento

1. Define qué afirmaciones necesita el guion para sostener su historia.
2. Busca primero fuentes primarias cuando existan: documentos, archivos, registros, declaraciones originales, estudios o material del periodo.
3. Contrasta con fuentes secundarias serias e independientes.
4. Verifica nombres, fechas, lugares, cifras, citas y secuencia de acontecimientos.
5. Comprueba si la fuente habla del hecho directamente o repite una versión de terceros.
6. Registra las discrepancias y qué versión tiene mejor respaldo.
7. Conserva las fuentes junto a las afirmaciones que respaldan.

## Reglas de investigación

- Para afirmaciones centrales de un caso real, intenta encontrar más de una fuente independiente.
- Una búsqueda rápida no equivale a verificación.
- No inventes citas, documentos, expertos, testigos ni detalles sensoriales.
- Si una fuente no se puede abrir o comprobar, indícalo.
- Si no hay evidencia para resolver un misterio, el guion debe preservar esa incertidumbre.
- No uses una fuente viral como prueba solo porque muchas cuentas repitan lo mismo.

## Construcción del ángulo

Después de investigar, identifica:

- El dato más inesperado que sí está respaldado.
- La contradicción más interesante entre versiones, si existe.
- La pregunta que la evidencia permite responder.
- El punto que continúa sin explicación.
- El orden más claro para revelar la información.

## Entregable

Crea una ficha breve con:

- Resumen factual del tema.
- Cronología, cuando corresponda.
- Afirmaciones verificadas y fuente de cada una.
- Testimonios, leyendas o hipótesis claramente etiquetados.
- Controversias o datos inciertos.
- Detalles que no deben incluirse.
- Ángulos narrativos posibles.

La investigación debe ser proporcional al tema. Una historia ficticia o una pieza puramente creativa no necesita fingir una investigación factual.
