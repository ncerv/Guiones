# Biblioteca de llamadas a la acción

## Principio

El CTA debe servir al objetivo del video y a la relación con la audiencia. No es obligatorio incluirlo si interrumpe un cierre que funciona mejor sin él.

## Tipos de objetivo

- **Seguir:** cuando existe una continuación o una promesa editorial reconocible.
- **Comentar:** cuando hay una pregunta genuina o una experiencia que la audiencia puede aportar.
- **Guardar:** cuando el video contiene información útil para volver a consultar.
- **Compartir:** cuando el tema puede ser relevante para otra persona o conversación.
- **Ver otra pieza:** cuando existe una continuación concreta y disponible.

## Reglas

1. Escoge una acción principal, salvo que exista una razón editorial clara para otra combinación.
2. Pide una acción específica y natural.
3. No prometas una parte 2, respuesta o material que no esté previsto.
4. No uses frases genéricas que podrían cerrar cualquier video.
5. El CTA puede ser hablado, visual o ambos; elige según el formato y la claridad.
6. No sacrifiques el último dato, la conclusión o la emoción de cierre por pedir interacción.
7. No atribuyas éxito al CTA sin observar métricas relevantes.

## Registro de patrones

Para cada CTA que se pruebe, registra la redacción, el objetivo, el tipo de video, las métricas disponibles y la ficha o publicación relacionada. El resultado no debe generalizarse a temas diferentes sin evidencia.
