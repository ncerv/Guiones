# Biblioteca de ganchos

## Función

Ayudar a encontrar una entrada específica, clara y honesta para cada historia. Un gancho no es una frase llamativa aislada: establece una promesa narrativa que el resto del video debe cumplir.

## Regla de uso

- Consulta los patrones que mejor encajen con el tema y el ángulo.
- Genera alternativas realmente distintas, no tres versiones de la misma frase.
- No es obligatorio cumplir dos reglas. La claridad y la promesa cumplible pesan más que la cantidad de técnicas presentes.
- No prometas una revelación que la investigación no permite entregar.
- Evita el clickbait engañoso, las afirmaciones absolutas sin prueba y el falso misterio.

## Catálogo provisional heredado

Estos recursos proceden de la versión anterior. Se conservan como ideas para experimentar; todavía no son hallazgos demostrados por el proyecto hasta vincularlos a fichas reales.

| Código | Recurso | Puede servir cuando… | Cuidado principal |
|---|---|---|---|
| H01 | Pregunta directa | El espectador puede imaginarse dentro de una situación | No hacer preguntas obvias o retóricas |
| H02 | Romper una creencia | Existe una versión popular que la evidencia contradice | No inventar una falsa creencia común |
| H03 | Empezar por la consecuencia | El resultado despierta una pregunta fuerte | No revelar toda la recompensa |
| H04 | Misterio abierto | Hay una incógnita real y delimitada | No insinuar que existe respuesta si no la hay |
| H05 | Número concreto | Hay una lista o secuencia genuina | No forzar números para crear expectativa |
| H06 | Advertencia | La advertencia es relevante para el relato | No fingir peligro o prohibición |
| H07 | Testimonio en primera persona | Existe un testimonio real o una narración ficticia declarada | Nunca inventar que el narrador estuvo allí |
| H08 | Frase interrumpida / loop | La información se completa poco después | No acumular promesas sin resolverlas |
| H09 | Detalle sensorial | Un detalle concreto está documentado o se presenta como recurso ficticio | No fabricar detalles en casos reales |
| H10 | Dato poco conocido | Hay un dato verificable y relevante | Evitar «nadie sabe» si sí se conoce |
| H11 | Pregunta con respuesta parcial | Una respuesta breve abre una cuestión mayor | No demorar artificialmente lo evidente |
| H12 | Autoridad o fuente | La fuente tiene nombre, contexto y credibilidad | No usar «los expertos» como autoridad vacía |
| H13 | Contraste antes/después | El cambio está bien documentado o representado | No exagerar el contraste |
| H14 | Cuenta atrás | El límite de tiempo forma parte real de la historia | No añadir una cuenta atrás decorativa |
| H15 | Comparación inesperada | La comparación aclara o reencuadra el tema | No forzar analogías |
| H16 | Gancho visual | La imagen puede generar una pregunta por sí misma | Debe entenderse incluso en pantalla pequeña |
| H17 | Reto al espectador | El reto es fácil de comprender y se cumple | No prometer una experiencia que el video no entrega |
| H18 | Acción en frío | La acción inicial es comprensible sin contexto | No usar imágenes impactantes desconectadas |

## Registro de evidencia

Para cada patrón, añade:

- Estado: provisional / recurrente / respaldado / en revisión / retirado.
- Fichas de referencia.
- Casos donde funcionó y casos donde no encajó.
- Tipo de tema, audiencia, plataforma y duración.
- Limitaciones conocidas.

## Evaluación de un gancho

Califica de 1 a 5, justificando cada puntuación:

1. **Claridad:** ¿se entiende a la primera?
2. **Especificidad:** ¿promete algo concreto y no intercambiable con cualquier video?
3. **Curiosidad o tensión:** ¿abre una pregunta que importa?
4. **Credibilidad:** ¿la frase está respaldada por el contenido?
5. **Entrega:** ¿el guion puede cumplir la promesa sin relleno?

La puntuación sirve para comparar alternativas, no para fingir precisión matemática. Un gancho sencillo y claro puede ser mejor que uno con más recursos.
